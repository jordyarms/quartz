### Docker Compose Commands
Start services
```sh
docker-compose up
```
Start services in the background
```sh
docker-compose up -d
```
Rebuild services
```sh
docker-compose up --build
```
Stop services
```sh
docker-compose down
```
View logs
```sh
docker-compose logs
```
